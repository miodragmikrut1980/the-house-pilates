# THE HOUSE Pilates · predlog sajta

Demo sajt za pitch vlasnicama studija THE HOUSE Pilates (Novi Sad). Nije zvanični sajt studija.

- Statičan sajt (HTML, CSS, JS), bez build koraka. Na Vercelu: Import → Deploy, bez podešavanja.
- `vercel.json`: čisti URL-ovi (`/programi`, `/cenovnik`...) i `noindex` zaglavlje.
- `robots.txt` i `<meta name="robots" content="noindex">` na svim stranama, da Google ne prikazuje predlog umesto njihovog sajta.
- Rezervacija i prijave su demo i ne šalju podatke nigde.

Stranice: `/` (početna sa rasporedom i rezervacijom), `/programi`, `/cenovnik`, `/studio`, `/edukacije`, `404`.
